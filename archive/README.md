# Archive — source material, not deployed

Nothing in this folder is served by the website. It is kept in git because it cannot be regenerated.
Exclude `archive/` from any deploy or build step.

## `photos-highres/`

**These are the highest-resolution photographs of this business's work that exist.** There are no
better originals anywhere — confirmed during the 2026 cleanup. Every product photo on the old website
was a heavily downscaled copy (median ~275×640 px); these are the camera files.

- `prt1.jpg`, `prt2.jpg`, `prt3.jpg` — altar cloths, 4.7–6.3 MB each. The largest images available.
- `plasc1–4`, `stola.JPG`, `alba.JPG`, `srajce.jpg`, `1.jpg`, `2.jpg`, `spodaj.jpg` — vestments,
  0.4–1.8 MB each. Previously sat unused in `slike/novo/`.
- `DSCN*.JPG`, `HPIM*.JPG` — unedited camera originals from the old `FB/` folder (never published).
- `miklavževa-obleka.JPG` — small (17 KB), only low-res copy of a St. Nicholas costume.

These are the only files suitable for large hero imagery in the new design. Treat them as the master
set: derive web-sized variants from them, never overwrite them.
